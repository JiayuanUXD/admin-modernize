# 数据层清单

每一项在数据层统一实现一次，页面按约定使用。

| 项 | 要统一的内容 | 页面里不该出现 |
|---|---|---|
| 请求封装 | 基础地址、超时、取消、重试（仅幂等请求）、并发去重 | 各自配置地址和超时 |
| 响应外壳 | 成功与失败的判定、业务码、数据所在路径，在一处解包 | `res.data.data.list` 这类逐层取值 |
| 分页 | 页码和页大小的命名、从 0 还是 1 起、总数字段 | 页面里 `current → page` 这类改名 |
| 排序与筛选 | 参数形态、多字段排序、区间参数 | 每页自拼筛选参数 |
| 错误处理 | 业务码到用户提示的映射；网络错误、超时、401、403、5xx 的统一处理；表单字段级错误回填 | 每个请求各写 catch 和提示 |
| 鉴权与权限 | 令牌刷新；权限点来源；页面与按钮的声明方式 | 页面里判断角色字符串 |
| 字典与枚举 | 获取、缓存、值与标签的映射 | 页面里写死数字枚举和文案 |
| 日期与时区 | 传输格式（ISO 字符串或时间戳）、展示格式、时区 | 手写日期格式化与拼接 |
| 金额与数量 | 传输类型（字符串小数或最小单位整数）、展示精度、千分位、负数展示 | 浮点运算 |
| 文件 | 上传（大小限制、进度、分片）、下载与导出（流或异步任务）、文件名编码 | 各页自写上传下载 |
| 重复提交与幂等 | 按钮锁、请求幂等键 | 各页自己防抖 |
| 加载、空、错误态 | 统一的承载组件与触发方式 | 每页自己画空态 |
| 日志与追踪 | 请求 id、埋点事件 | 页面里散落的埋点 |

填清单时记三栏：约定是什么、谁实现、页面怎么用。后端约定不一致的项，在适配层写明映射，并记入给后端的接口规范。
