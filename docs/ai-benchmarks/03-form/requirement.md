# 登记表单

操作员打开一张空白登记表，先拉枚举，再提交。校验失败停在原页；提交成功后进入只读详情。

| 操作 | 方法 + 路径 | 请求 |
|---|---|---|
| 枚举 | `GET /api/meta` | 无 |
| 提交 | `POST /api/registrations` | `title`、`kind`、`actor` |
| 详情 | `GET /api/registrations/{id}` | 无请求体 |

`kind` 的取值只来自 `GET /api/meta`，页面里不写死枚举。

契约片段：`contract.openapi.json`。

## 自动检查

- 仓库的检查命令对这次改动退出码 0。
- 截图命令退出码 0：桌面和窄屏都要有空白表单、校验失败、提交成功后的详情。

## 人工检查

- 校验失败时已填字段还在。
- 枚举选项和 meta 响应一致，页面源码里没有第二份列表。
- 成功之后不再显示提交按钮。
