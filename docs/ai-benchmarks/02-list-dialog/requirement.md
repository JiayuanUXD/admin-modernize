# 订单：列表 + 备注弹窗

客服打开订单列表，点一行弹出备注对话框，提交后对话框关闭，列表上的备注列更新。

| 操作 | 方法 + 路径 | 请求 |
|---|---|---|
| 列表 | `GET /api/orders` | 查询参数 `status` 可选 |
| 详情 | `GET /api/orders/{id}` | 无请求体 |
| 写备注 | `POST /api/orders/{id}/note` | `note`、`actor` |

契约片段：`contract.openapi.json`。

## 自动检查

- 仓库的检查命令对这次改动退出码 0。
- 截图命令退出码 0：桌面和窄屏都要有列表，以及弹窗打开、提交失败两种状态。

## 人工检查

- 弹窗盖在列表上，关闭后列表的筛选条件还在。
- 提交失败时备注留在输入框里，不把对话框关掉假装成功。
- 备注列能显示空备注，不用占位订单顶上。
